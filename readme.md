# Tests

## Running the Tests

All test commands should be executed from the **root folder of the project**.

To run all available tests:

```bash
./run_tests.sh all
```

To run a specific test, provide the path to the test file:

```bash
./run_tests.sh [subfolder/name]
```

For example:

```bash
./run_tests.sh advanced_tests/polymorphic.txt
```

The Rust programs generated by the tests and their outputs will be placed in the:

```text
test_outputs/
```

folder.

## Running Ferrite Files

To run the genereted programs in Ferrite, first clone the Ferrite repository:

```bash
git clone https://github.com/ferrite-rs/ferrite.git
```

Then follow the installation and usage instructions provided in the Ferrite repository's `README.md`.

The Ferrite repository can be found here:

https://github.com/ferrite-rs/ferrite
